# ROCK-PAPER-SCISSORS TOURNAMENT PLATFORM
## Detailed Application Specifications v1.0

---

## 1. PROJECT OVERVIEW

### 1.1 Project Name
RPS Tournament Platform (working title)

### 1.2 Project Vision
A mobile-responsive web application for managing and playing tournament-based Rock-Paper-Scissors games with support for multiple game variants, detailed statistics tracking, and both live and digital gameplay modes.

### 1.3 Core Concept
- Default game: Rock, Paper, Scissors
- Extensible to custom game types (e.g., Rock, Paper, Scissors, Hammer, Nail)
- Tournament management with automatic bracket generation
- Player registration and stat tracking
- Dual play modes: Digital face-to-face and Live recording

---

## 2. USER ROLES & AUTHENTICATION

### 2.1 User Types
1. **Anonymous User** - Can view public tournaments
2. **Registered Player** - Has email tied to account, can claim matches and view personal stats
3. **Tournament Organizer** - Can create tournaments, add players, manage matches
4. **Admin** - Full system access

### 2.2 Player Management
- Players can be created without email addresses (for quick tournament setup)
- Players can optionally provide email addresses to claim their profiles
- Email-registered players can:
  - Login to view their statistics
  - See match history
  - View lifetime achievements
  - Track performance metrics

## 3. GAME TYPES & RULES

### 3.1 Game Type System
- Each game type is independently defined
- Game types include:
  - Symbol set (e.g., Rock, Paper, Scissors)
  - Win/loss matrix (what beats what)
  - Scoring methodology
  - Visual assets (icons, animations)

### 3.2 Default Game Type: Classic RPS
**Symbols:**
- Rock 🪨
- Paper 📄
- Scissors ✂️

**Rules:**
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same symbol = Tie

### 3.3 Future Game Types
- Extensible system to add variants (e.g., Rock, Paper, Scissors, Lizard, Spock)
- Custom game types with unique symbol sets
- Each game type has its own scoring system

## 4. MATCH TYPES & FORMATS

### 4.1 Quick Match (Primary Mode)
- Click "Play" button
- System finds available opponent
- Configurable match settings:
  - Best of 3 (ties don't count)
  - Best of 5 (ties don't count)
  - Best of 7, 9, 11, etc.
  - Best of N (with reasonable upper limit, e.g., N ≤ 31)

### 4.2 Tournament Match
- Part of organized tournament bracket
- Follows tournament-specific rules
- Results feed into bracket progression

### 4.3 Match Configuration Options
- Game type selection
- Number of rounds (best of N)
- Tie handling (ties don't count by default)
- Time limits per round (optional)

## 5. GAMEPLAY MODES

### 5.1 Mode 1: Digital Face-to-Face Play
**Description:** Two players face each other with their phones for actual gameplay

**Flow:**
1. Players enter a match together
2. Each player sees their perspective on their own device
3. Can see opponent's screen (facing each other)
4. App displays countdown: "Rock... Paper... Scissors... SHOOT!"
5. Both players select their icon simultaneously
6. Results are displayed immediately

**Victory Animation:**
- Confetti falls from top of screen
- Screen stays normal color (NO green background)

**Loss Animation:**
- Player's selected hand explodes with animation
- Screen stays normal color (NO red background)

**Round History:**
- After round ends, both selected symbols animate and fly to top-left corner
- Previous rounds displayed as minimized cards in chronological order
- Players can see complete match history at a glance

### 5.2 Mode 2: Live Recording Mode
**Description:** Manual recording of physical gameplay

**Purpose:**
- Record results of games played in real life
- Maintains tournament integrity by logging physical matches
- Allows tournament progression without digital gameplay

**Flow:**
1. Observer/referee mode
2. Players play physical RPS
3. Observer marks the winner and move used
4. Results count toward tournament standings

**Features:**
- Quick input for: Win/Loss/Tie
- Symbol selection for both players
- Timestamp recording
- Match context (tournament tie-in)

## 6. TOURNAMENT SYSTEM

### 6.1 Tournament Creation
**Setup Flow:**
1. Tournament organizer selects "Create Tournament"
2. Provides tournament name and description
3. Selects game type
4. Adds player list (names, optional emails)
5. Configures match format (best of N)
6. System automatically generates bracket

### 6.2 Tournament Bracket
- Automatic bracket generation based on player count
- Standard single-elimination or double-elimination
- Visual bracket display
- Real-time updates as matches complete

### 6.3 Tournament Management
- Add/remove players before start
- Track match completion status
- View current round
- Progress to next round automatically when current round completes

## APPENDIX A: GAME ANIMATIONS SPECIFICATION

### Victory Animation - Confetti
- **Trigger:** Player wins a round
- **Effect:** Confetti particles fall from top of screen
- **Colors:** Rainbow/multi-colored
- **Duration:** 2-3 seconds
- **Particle Count:** 50-100 pieces
- **Physics:** Realistic gravity and slight horizontal drift
- **Background:** Normal (no color change)

### Loss Animation - Hand Explosion
- **Trigger:** Player loses a round
- **Effect:** Selected hand symbol explodes into particles
- **Duration:** 1-2 seconds
- **Particle Behavior:** Radial burst from center
- **Background:** Normal (no color change)

### Round End Transition
- **Trigger:** Round completes (after win/loss animation)
- **Effect:** Both symbol cards animate to top-left corner
- **Animation Type:** Smooth fly/slide with easing
- **Target Position:** Top-left corner, stacked chronologically
- **Final Size:** Thumbnail (20-25% of original size)
- **Display:** Vertical or horizontal stack showing round history
